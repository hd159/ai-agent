# Compose Team

1. Read the project goal, constraints, and lifecycle stage.
2. Read the project's team manifest or available team presets.
3. Identify required capabilities, not just job titles.
4. Select the smallest team that covers required ownership.
5. Avoid duplicate specialists with overlapping responsibilities.
6. Identify optional reviewers separately from required implementers.
7. Confirm each selected agent is available in the bundled plugin or clearly mark it missing.
8. Produce a team composition summary and unresolved capability gaps.

Output: selected agents, responsibilities, dependencies, optional roles, missing agents or capabilities, and rationale.
