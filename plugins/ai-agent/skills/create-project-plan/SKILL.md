# Create Project Plan

1. Confirm discovery and MVP scope are approved.
2. Identify lifecycle stages and required artifacts.
3. Add architecture and specialist review checkpoints.
4. Define contract freeze points before parallel implementation.
5. Define integration and quality gates.
6. Identify user approvals and external dependencies.
7. Keep milestones outcome-based and testable.

Output: project plan, stage owners, deliverables, dependencies, approval gates, and risks.
