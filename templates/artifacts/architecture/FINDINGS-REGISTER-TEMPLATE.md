## Status definitions

- Open: recorded, validation incomplete.
- Confirmed: supported by current source or reproducible evidence.
- In Progress: remediation underway.
- Fixed Pending Verification: code changed; independent verification is outstanding.
- Verified Fixed: acceptance criteria and tests demonstrate resolution.
- Accepted Risk: explicitly approved with rationale and review date.
- Stale: original condition no longer exists.
- False Positive: original claim was incorrect.
- Needs Verification: evidence is insufficient to confirm or dismiss.

Never mark a finding Verified Fixed based only on an implementation-agent statement.
