# Evaluation Plan

A skill or agent is not considered ready solely because its prompt looks plausible.

For each new agent/skill:
- Add at least one normal-use scenario.
- Add at least one ambiguity or adversarial scenario.
- Add at least one negative scenario where the skill/agent should not activate.
- Evaluate output contract adherence.
- Evaluate evidence quality and unsupported claims.
- Record regressions before changing shared instructions.
