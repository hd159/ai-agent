# Codex Adapter — Planned

Not implemented in v0.2.0.

The intended adapter will map:
- Canonical Agent Skills to Codex-supported skill directories.
- Specialist identity and boundaries to Codex agent configuration where supported.
- Team manifests to explicit task/handoff artifacts or a compatible orchestration runtime.

Do not assume Antigravity `module.json` or agent frontmatter is portable to Codex.
